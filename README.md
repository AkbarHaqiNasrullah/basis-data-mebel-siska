# Sistem Basis Data Toko Mebel Siska

Project mata kuliah Basis Data (Kelompok 8). Merancang database untuk toko mebel yang mencatat pekerja, produk, pelanggan, dan pembelian.

## Struktur Tabel

- `pekerja`
- `toko`
- `produk`
- `pembelian`
- `pelanggan`

## Materi yang Diterapkan

- DDL (`CREATE DATABASE`, `CREATE TABLE`) dan DML (`INSERT`)
- Subquery (Scalar, `IN`, `ANY`, `ALL`)
- Stored Procedure (parameter `IN`)

## Teknologi

- MySQL
- MySQL Workbench

## Cara Menjalankan

1. Buka MySQL Workbench.
2. Buka file `projectpas_8.sql`.
3. Jalankan seluruh script (ikon petir).
4. Database `projectpas_8` akan terbentuk beserta datanya.
